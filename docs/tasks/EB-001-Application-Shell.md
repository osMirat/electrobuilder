# EB-001 — Application Shell

## Цель

Создать базовый каркас интерфейса ElectroBuilder.

## Требования

Интерфейс должен состоять из:

### Верхняя панель

Высота около 64 px.

Содержит:

* логотип ⚡ ElectroBuilder;
* строку поиска (пока неактивную);
* пользователя справа.

---

### Левая панель

Ширина около 260 px.

Пункты меню:

* 📁 Проекты
* 🏠 Объекты
* 🚪 Помещения
* ⚡ Линии
* ⚙ Щиты
* 📄 Документы
* ⚙ Настройки

---

### Центральная область

Показывает:

# Добро пожаловать в ElectroBuilder

Текст:

Создайте первый проект, чтобы начать работу.

Кнопка:

* Создать проект

---

### Нижняя строка состояния

Высота около 32 px.

Показывает:

Ready

v0.1.0-alpha

---

## Стиль

Использовать shadcn/ui.

Минималистичный интерфейс.

Основной цвет — Slate.

Акцент — синий.

Большие внутренние отступы.

Светлая тема.

---

## Запрещено

Не использовать:

* API;
* Prisma;
* PostgreSQL;
* локальное хранилище;
* авторизацию.

---

## Definition of Done

* приложение запускается;
* отсутствует стандартная страница Next.js;
* отображается интерфейс ElectroBuilder;
* адаптивность для ширины экрана от 1024 px.
