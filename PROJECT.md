# ElectroBuilder

## Что это

ElectroBuilder — профессиональное web-приложение для электромонтажников.

Цель — помочь создавать проекты электрощитов, рассчитывать линии, подбирать оборудование, формировать схемы и документацию.

---

## Главные принципы

* Код должен быть чистым.
* Архитектура должна быть масштабируемой.
* Один источник истины для данных.
* Минимум дублирования.
* Каждая функция должна быть независимым модулем.

---
